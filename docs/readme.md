DIGITAL BRIDGE

VISION

Digital Bridge est une plateforme qui connecte les personnes autour de 3
axes principaux : - Collaboration - Financement - Immobilier

L’objectif est de créer un écosystème économique où les idées, les
talents, le capital et l’immobilier se rencontrent.

------------------------------------------------------------------------

LES 3 AXES PRINCIPAUX

1)  COLLABORATION

-   Associé : rejoindre un projet existant
-   Co-founder : construire un projet dès le départ
-   Freelance : mission spécifique
-   Salarié : contrat fixe

Use case : J’ai un projet et je cherche quelqu’un pour travailler avec
moi.

------------------------------------------------------------------------

2)  FINANCEMENT

-   Equity (part du projet)
-   Loan (prêt)
-   Revenue share (part des bénéfices)
-   À discuter

Use case : J’ai une idée mais je cherche un financement.

------------------------------------------------------------------------

3)  IMMOBILIER (Feature forte de la plateforme)

-   Achat en commun
-   Gestion Airbnb
-   Sous-location
-   Investissement immobilier

Use case : Je cherche un partenaire pour investir ou gérer un bien
immobilier.

------------------------------------------------------------------------

STACK TECHNIQUE

Frontend : - NextJS 16 (App Router) - React 19 - TypeScript -
TailwindCSS v4

Backend : - NestJS 11 - Prisma ORM - PostgreSQL - JWT Auth (Access +
Refresh token via httpOnly cookie)

------------------------------------------------------------------------

USER MODEL ACTUEL

User : - role (USER / ADMIN) - profileType (INDIVIDUAL, ENTREPRENEUR,
INVESTOR, AGENCY, COMPANY) - interests (COLLABORATION, FINANCEMENT,
IMMOBILIER)

C’est une plateforme structurée autour de : - Collaboration économique -
Financement structuré - Partenariats immobiliers
